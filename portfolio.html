Technical Pipeline Strategy

Using custom Python scripts to automate texture baking and UV unwrapping, we reduced the per-asset render time by 40%. The dense simulation mesh from CLO3D was retopologized and optimized in Blender before export to Avataar's real-time engine to ensure maximum frame rates on mobile web AR.

  • Core Tools CLO3D, Blender, Python Scripts
  • Rendering Cycles / Eevee Engine
  • Poly Output 2M Polys → Highly Optimized 50k
  • Automation 70% manual stage reduction
03 / System Build

VP Configurator Engine

A production-level real-time 3D garment engine designed for modular mix & match styling. Built using Three.js with Draco-compressed GLB assets, custom HDR-based lighting, and a scalable folder architecture. The engine demonstrates systemic thinking, complex garment layering logic, and independent material control within a high-performance browser-based environment.

Engine Capabilities

  • Real-time WebGL rendering pipeline
  • Draco-optimized GLB asset loading
  • Dynamic Men / Women mannequin switching
  • Mix & Match rules (Top / Bottom / Jacket conflicts)

Architecture Logic

  • Modular ES6 Component Structure
  • Environment State Manager
  • Garment Dependency Controller
  • Dynamic Color / Material Injection
